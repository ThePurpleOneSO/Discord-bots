# Discord Music Bot (Python)

## Overview
A simple Discord bot built with Python that can play music files in voice channels.  
It supports basic playback commands and is designed for learning and portfolio use.

## Features
- 🎵 Play local music files (MP3, WAV)  
- ⏯️ Pause, resume, and stop playback  
- 📂 Queue multiple songs  
- 🔊 Join and leave voice channels  

## Tech Stack
- Python 3.x  
- discord.py library  
- FFmpeg (for audio playback)  
- dotenv (for secure token management)
